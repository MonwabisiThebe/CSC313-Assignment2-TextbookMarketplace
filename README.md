#  Textbook Marketplace App (CSC313 Assignment 2)

##  Overview

This project is an Android application developed for **CSC313: Object-Oriented Programming Assignment 2**.  
It demonstrates the application of **Object-Oriented Programming (OOP) principles**, **exception handling**, **interfaces**, and **abstract classes** in a real-world textbook marketplace system.

The app allows users to browse, list, and search textbooks for sale while ensuring proper data validation and preventing duplicate entries.

---

##  Features

### 1.  Browse Available Textbooks
- View all textbooks currently listed for sale
- Displays:
    - Title
    - Seller name
    - Number of copies
    - Price
    - Banking/payment information

---

### 2. List a Textbook for Sale
- Users can add a textbook with the following details:
    - Title
    - Seller name
    - Number of copies
    - Selling price
    - Banking/payment information
- Supports multiple listings

---

### 3. Duplicate Prevention
- The system prevents users from adding duplicate textbooks
- Uses custom exception handling (`DuplicateBookException`)

---

### 4. Search Functionality
- Users can search textbooks by:
    - Book title
    - Seller name
- Displays matching results dynamically
